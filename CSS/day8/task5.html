HTML (HyperText Markup Language) is the standard language used to create web pages. It provides the basic structure of a website using different elements and tags.

CSS (Cascading Style Sheets) is used to style and design web pages. It controls colors, fonts, spacing, layouts, and responsive designs.

JavaScript is a programming language that makes web pages interactive. It is used to create dynamic content, animations, and user-friendly applications.
