Variable Declaration in JavaScript

Variable declaration means creating a variable and telling JavaScript that the variable exists.

JavaScript Variable Keywords

JavaScript provides three keywords for declaring variables:

  • var
  • let
  • const

var Declaration

var is used to declare a variable. 

var name;

let Declaration

let is used to declare a variable whose value can be changed later. 

let age;
age = 25;

const Declaration

const is used to declare a variable whose value cannot be reassigned after initialization. 

const country = "India";

Simple Comparison

Keyword Declaration Reassignment
var Yes Yes
let Yes Yes
const Yes No

Data Types in JavaScript

A data type tells JavaScript what kind of value is stored in a variable.

Types of Data Types

JavaScript data types are mainly divided into two categories:

  • Primitive Data Types
  • Non-Primitive Data Types

1. Primitive Data Types

Primitive types store a single value.

String

Used to store text.

let name = "Praveen";

Number

Used to store numbers.

let age = 25;

BigInt

Used for very large integers.

let bigNumber = 12345678901234567890n;

Boolean

Stores true or false.

let isStudent = true;

Undefined

Variable is declared but no value is assigned.

let city;

Null

Represents an intentionally empty value.

let result = null;

Symbol

Creates a unique value.

let id = Symbol("id");

2. Non-Primitive Data Type

Objects can store multiple values using key-value pairs. 

let student = {
    name: "Praveen",
    age: 25
};

Simple Comparison

Data Type Example Meaning
String "Hello" Text
Number 25 Numbers
BigInt 100n Large integer
Boolean true True / False
Undefined undefined No value assigned
Null null Empty value
Symbol Symbol() Unique value
Object { } Collection of data

Remember

Data type tells JavaScript what kind of value is stored in a variable.

Operators in JavaScript

An operator is a symbol that tells JavaScript to perform an operation on values.

1. Arithmetic Operators

Used to perform mathematical calculations. 

let a = 10;
let b = 3;

console.log(a + b);  // 13
console.log(a - b);  // 7
console.log(a * b);  // 30
console.log(a / b);  // 3.33
console.log(a % b);  // 1
console.log(a ** b); // 1000
Operator Meaning
+ Addition
- Subtraction
* Multiplication
/ Division
% Remainder
** Power

2. Assignment Operators

Used to assign or update a value in a variable. 

let x = 10;

x += 5;
x -= 3;
x *= 2;
x /= 4;

3. Comparison Operators

Used to compare two values. The result is usually true or false. 

let a = 10;
let b = 5;

console.log(a > b);   // true
console.log(a < b);   // false
console.log(a === b); // false

4. Logical Operators

Used to combine or reverse conditions. 

&&  → AND
||  → OR
!   → NOT

5. Increment and Decrement

Increment increases a value by 1. Decrement decreases a value by 1. 

let count = 5;

count++;
console.log(count); // 6

count--;
console.log(count); // 5

6. Ternary Operator

The ternary operator is a short way of writing an if...else condition. 

let age = 20;

let result = age >= 18 ? "Adult" : "Minor";

console.log(result); // Adult

Remember

  • Arithmetic → Calculate
  • Assignment → Give or update value
  • Comparison → Compare values
  • Logical → Combine conditions
  • Increment / Decrement → Increase or decrease by 1
  • Ternary → Short if...else

Conditional Statements in JavaScript

Conditional statements are used to make decisions in JavaScript. They check a condition and execute code based on whether it is true or false.

1. if Statement

The if statement runs code only when the condition is true. 

let age = 20;

if (age >= 18) {
    console.log("You can vote");
}

2. if...else Statement

It provides two choices: one when the condition is true and another when it is false. 

let age = 16;

if (age >= 18) {
    console.log("You can vote");
} else {
    console.log("You cannot vote");
}

3. else if Statement

else if is used when there are multiple conditions. 

let mark = 75;

if (mark >= 90) {
    console.log("A Grade");
} else if (mark >= 60) {
    console.log("B Grade");
} else if (mark >= 40) {
    console.log("C Grade");
} else {
    console.log("Fail");
}

4. switch Statement

switch is useful for choosing one option from multiple possible values. 

let day = 2;

switch (day) {
    case 1:
        console.log("Monday");
        break;

    case 2:
        console.log("Tuesday");
        break;

    default:
        console.log("Invalid day");
}

5. Ternary Operator

The ternary operator is a short way of writing an if...else statement. 

let age = 20;

let result = age >= 18 ? "Adult" : "Minor";

console.log(result);

Simple Comparison

Statement Use
if One condition
if...else Two choices
else if Multiple conditions
switch Multiple choices for one value
Ternary Short if...else

Remember

Conditional statements help JavaScript make decisions based on conditions.

Loops in JavaScript

A loop is used to repeat the same code multiple times.

1. for Loop

Used when we know how many times we want to repeat something. 

for (let i = 1; i <= 5; i++) {
    console.log(i);
}

2. while Loop

Runs as long as the condition is true. 

let i = 1;

while (i <= 5) {
    console.log(i);
    i++;
}

3. do...while Loop

Runs the code at least once before checking the condition. 

let i = 1;

do {
    console.log(i);
    i++;
} while (i <= 5);

4. for...of Loop

Used to get values one by one from an array or other iterable. 

let fruits = ["Apple", "Mango", "Orange"];

for (let fruit of fruits) {
    console.log(fruit);
}

5. for...in Loop

Used to get object keys one by one. 

let student = {
    name: "Praveen",
    age: 25
};

for (let key in student) {
    console.log(key);
}

Simple Comparison

Loop Use
for Known number of repetitions
while Run while condition is true
do...while Run once, then check
for...of Get values
for...in Get object keys

Remember

A loop helps us repeat code without writing the same code again and again.

Functions in JavaScript

A function is a block of code designed to perform a specific task. We can call a function whenever we need it.

1. Function Declaration

A function is created using the function keyword. 

function greet() {
    console.log("Hello");
}

greet();

2. Parameters and Arguments

Parameters are variables written when creating a function. Arguments are the actual values passed when calling it. 

function add(a, b) {
    return a + b;
}

console.log(add(10, 5));

3. Return Statement

return sends a value back from the function. 

function square(n) {
    return n * n;
}

console.log(square(5));

4. Arrow Function

An arrow function is a shorter way to write a function. 

const add = (a, b) => {
    return a + b;
};

console.log(add(10, 5));

Simple Comparison

Term Meaning
Function Reusable block of code
Parameter Variable in function definition
Argument Value passed to a function
return Sends a value back
Arrow Function Shorter function syntax

Remember

A function lets us write code once and reuse it whenever we need it.

Arrays & Array Methods in JavaScript

An array is used to store multiple values in a single variable.

1. Creating an Array

An array can store multiple values inside square brackets. 

let fruits = ["Apple", "Mango", "Orange"];

console.log(fruits);

2. Accessing Array Elements

Array indexes start from 0. 

let fruits = ["Apple", "Mango", "Orange"];

console.log(fruits[0]); // Apple
console.log(fruits[1]); // Mango

3. push()

Adds an element to the end of an array. 

fruits.push("Banana");

4. pop()

Removes the last element from an array. 

fruits.pop();

5. unshift()

Adds an element to the beginning of an array. 

fruits.unshift("Grapes");

6. shift()

Removes the first element from an array. 

fruits.shift();

Common Array Methods

Method Use
push() Adds element at the end
pop() Removes last element
unshift() Adds element at the beginning
shift() Removes first element
slice() Returns a portion of an array
splice() Adds or removes elements
includes() Checks if an element exists
indexOf() Finds the index of an element
join() Converts array elements into a string

Remember

An array stores multiple values, and array methods help us add, remove, search, and modify those values.

Objects in JavaScript

An object is used to store multiple related values in one variable. Objects store data in key-value pairs.

1. Creating an Object

We create an object using curly braces { }. 

let person = {
    name: "Praveen",
    age: 25,
    city: "Chennai"
};

2. Accessing Object Properties

We can access object values using dot notation or bracket notation. 

console.log(person.name);
console.log(person["age"]);

3. Adding a Property

We can add a new property to an existing object. 

person.email = "praveen@gmail.com";

4. Changing a Property

We can change the value of an existing property. 

person.age = 26;

5. Deleting a Property

The delete keyword removes a property from an object. 

delete person.city;

6. Object Method

A function inside an object is called a method. 

let student = {
    name: "Praveen",

    greet: function() {
        console.log("Hello");
    }
};

student.greet();

7. Nested Object

An object can contain another object. 

let student = {
    name: "Praveen",

    address: {
        city: "Chennai"
    }
};

console.log(student.address.city);

Simple Comparison

Term Meaning
Object Stores related data
Key Property name
Value Data stored in a property
Method Function inside an object
delete Removes a property

Remember

An object stores related information using key-value pairs.

DOM & Events in JavaScript

DOM allows JavaScript to access and change HTML elements on a webpage. Events are actions that happen on a webpage, such as clicking or typing.

1. What is DOM?

DOM stands for Document Object Model. It allows JavaScript to access and change HTML elements. 

<h1 id="title">Hello</h1>

let title = document.getElementById("title");

title.textContent = "Welcome";

2. Selecting Elements

JavaScript provides methods to select HTML elements. 

document.getElementById("title");

document.querySelector("h1");

document.querySelectorAll("li");

3. Changing Content

We can change the text or HTML content of an element. 

title.textContent = "JavaScript";

box.innerHTML = "<b>Hello</b>";

4. What are Events?

An event is an action that happens on a webpage.

  • Click
  • Mouseover
  • Input
  • Submit

5. addEventListener()

addEventListener() is used to listen for an event and run code when that event happens. 

let button = document.getElementById("btn");

button.addEventListener("click", function() {
    alert("Hello!");
});

6. DOM + Event Example 

<button id="btn">Click Me</button>
<h1 id="title">Hello</h1>

let button = document.getElementById("btn");
let title = document.getElementById("title");

button.addEventListener("click", function() {
    title.textContent = "Welcome to JavaScript!";
});

Simple Comparison

Term Meaning
DOM Access and change HTML
Event Action on a webpage
addEventListener() Listen for an event
click User clicks an element
input User types in an input

Remember

DOM helps JavaScript control the webpage, and Events tell JavaScript when something happens.

Asynchronous JavaScript

Asynchronous JavaScript allows some tasks to run without waiting for other tasks to finish.

1. Synchronous JavaScript

Synchronous code runs one task at a time, in order. 

console.log("First");
console.log("Second");
console.log("Third");

2. setTimeout()

setTimeout() runs a function after a specified delay. 

console.log("Start");

setTimeout(function() {
    console.log("Hello");
}, 2000);

console.log("End");

Output: Start → End → Hello

3. Callback Function

A callback is a function passed to another function to be executed later. 

function greet(callback) {
    console.log("Hello");
    callback();
}

greet(function() {
    console.log("Welcome");
});

4. Promise

A Promise represents a task that may be completed successfully or fail in the future. 

let promise = new Promise(function(resolve, reject) {
    resolve("Success");
});

promise.then(function(result) {
    console.log(result);
});

5. async / await

async and await make asynchronous code easier to write and understand. 

function getData() {
    return Promise.resolve("Data received");
}

async function showData() {
    let result = await getData();
    console.log(result);
}

showData();

Simple Comparison

Concept Meaning
Synchronous Runs one task at a time
setTimeout() Runs code after a delay
Callback Function executed later
Promise Represents a future result
async / await Simplifies asynchronous code

Remember

Asynchronous JavaScript allows tasks to happen without blocking other code from running.
